# TukangPLC Website

Situs edukasi TukangPLC tentang PLC, TwinCAT, dan PC-Based Control.

## Menulis artikel

Buat file di `_posts/` dengan format `YYYY-MM-DD-judul-singkat.md` dan front matter berikut:

```yaml
---
title: "Judul artikel"
date: 2026-10-27 09:00:00 +0700
categories: [artikel]
description: "Ringkasan satu kalimat."
---
```

Simpan isi artikel dalam Markdown setelah front matter. Artikel terbaru dalam kategori `artikel` otomatis muncul di beranda setelah GitHub Pages membangun ulang situs. Beranda menampilkan hingga tiga artikel; bagian tersebut tersembunyi jika belum ada posting.
